## Shared expectations
1. Every member contributes to programming and understands the overall application.
2. Members attend agreed meetings or notify the team in advance if unavailable.
3. Members communicate progress and blockers promptly.
4. Members commit their own work to feature branches and open pull requests for peer review.
5. Members do not commit passwords, API keys, database credentials, or `.env` files.
6. Members test their changes and help with integration and debugging.
7. Decisions about scope, deadlines, and role changes are made collectively.
8. Members treat each other respectfully and raise concerns early.
